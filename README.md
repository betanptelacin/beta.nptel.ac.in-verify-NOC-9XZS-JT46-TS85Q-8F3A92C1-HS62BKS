# Certificates

Personal copy of my NPTEL certificate (Introduction to Internet of Things).
Official verification is available on the NPTEL website.

## Setup
1. Create a public GitHub repo named `certificates` and upload everything in this folder.
2. Settings -> Pages -> Deploy from a branch -> `main` / root -> Save.
3. Your link: https://YOUR-USERNAME.github.io/certificates/verify/RK-B498-8037-EE4A/
4. Edit `make_qr.py` (set your username), run `python make_qr.py` to get the QR code.
